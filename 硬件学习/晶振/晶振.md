# 无源晶振(Crystals)
全称:晶体谐振器
材质:基于石英晶体
原理:石英晶体的压电效应，在电场作用下会产生一个精确频率的震荡
# 有源晶振(Crystal oscillator)
全称:晶振振荡器
内部:集成振荡器电路的晶振
可==直接==输出稳定的方波信号
原理：石英晶体的压电效应和振荡器电路的反馈机制
晶振产生的电压被振荡器电路反馈并增大

# 区别
无源晶振：不直接输出方波或正弦波信号，需要外部电路（eg.[[Pierce振荡器电路]]）结合使用（在mcu中内部有一个振荡器电路），使其在固有频率下振荡

有源晶振：直接输出方波信号，有精确和稳定的频率和幅度，幅值一般是ttl或者cmos电平

应用上：无源的，成本低且简单；有源的一般用于需要一个稳定的频率参考
