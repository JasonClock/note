# 背景
前端保护的传统方案是：肖特基二极管或者pmos
但是在输入大电流的情况下$P = U * I$会产生很大的功耗
于是诞生出了理想二极管的设计方案

# 电池反向保护
需要直接用电池供电的模块需要避免电池的反接或者由于后级的感性负载导致与电池断开一瞬间出现反向电动势的情况（由于$U = L*di/dt$)，有可能损坏电子元器件和导致电容老化

## 缺点：
- 功耗问题：在高电流负载情况下正向传导时会有较大的功耗
- 热管理：高功耗导致需要专门的散热器，成本和空间都会增加
- 反向漏电流：高压肖特基二极管（==？==）的反向漏电流随着结温升高而急剧增加而导致反向时有更大的损耗
- 下游电源转换器的裕量：比如，冷启动时（全车上电需要很大的启动电流）电压跌倒3V,而热启动时电压跌至4V,正向压降减小了电源转换器的裕量，因此变换器需要更大的工作电压裕量

# ORing 电源（多个二极管并联）
多个二极管并联增加系统冗余或增加N+1配置中的电源容量。
N+1冗余配置中使用肖特基二极管并联多个电源单元（PSU）。一般只需要N个电源作为负载供电，但是会额外提供一个电源单元以作为有一个电源单元故障时的冗余
