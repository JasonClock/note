# 二阶系统、小信号模型与状态空间平均法

## 1. 二阶系统

### 定义

最高阶导数为二阶的动态系统称为**二阶系统**。

例如串联 RLC 电路：
根据KVL：
$
[  
LC\frac{d^2v}{dt^2}+RC\frac{dv}{dt}+v=u  
]
$

---

### 为什么是二阶？

- 电感：$(v_L=L\dfrac{di}{dt})$
    
- 电容：$(i_C=C\dfrac{dv}{dt})$
    

二者结合后自然产生二阶导数，因此 **一个 L + 一个 C 通常形成二阶系统**。

---

### 特征方程

令输入为零（研究系统自身响应）：
$
[  
LCv''+RCv'+v=0  
]
$

假设解为
$( v=e^{st}  )$
代入得到
$
[  
LCs^2+RCs+1=0  
]
$
称为**特征方程**。

---

### 为什么有两个根？

因为二阶方程一定有两个根：

[  
s_1,s_2  
]

系统响应为

[  
v(t)=Ae^{s_1t}+Be^{s_2t}  
]

---

### 为什么通常是共轭复数？

对于实系数二次方程
$
[  
as^2+bs+c=0  
]
$
若判别式
$
[  
\Delta=b^2-4ac<0  
]
$
则
$
[  
s=-\alpha\pm j\omega  
]
$
根必须成共轭出现（实系数多项式性质）。

---

### 共轭复根的物理意义
$
[  
s=-\alpha+j\omega  
]
$
对应响应
$
[  
e^{st}
]
$
$
[
e^{-\alpha t}  
(\cos\omega t+j\sin\omega t)  
]
$
其中：

- 实部$(-\alpha)$：决定衰减速度（阻尼）
    
- 虚部 $(\omega)$：决定振荡频率
    

---

## 2. 二阶系统标准模型

标准传递函数
$
[  
H(s)=  
\frac{K\omega_0^2}  
{s^2+\frac{\omega_0}{Q}s+\omega_0^2}  
]
$
参数含义：

- (K)：直流增益
    
- $(\omega_0)$：固有角频率
    
- (Q)：品质因数（阻尼程度）
    

---

## 3. 小信号模型（Small-Signal Model）

### 为什么需要？

Buck、Boost 等开关电源本质是**非线性系统**：

例如

Boost
$
[  
V_o=\frac{V_{in}}{1-D}  
]
$
占空比变化时系统增益不是常数，因此不能直接用线性控制理论分析。

---

### 基本思想

在某一工作点附近：

把变量分解为

> **稳态值 + 微小扰动**

例如
$
[  
D=D_0+\hat d  
]
$
$
[  
v_o=V_O+\hat v_o  
]
$
$
[  
i_L=I_L+\hat i_L  
]
$
忽略二阶小量
$
[  
\hat d\hat v_{in}  
\approx0  
]
$
于是得到线性模型。

---

### 小信号模型作用

得到各种传递函数：

控制到输出

$
[  
G_{vd}(s)=\frac{\hat V_o(s)}  {\hat D(s)}  
]
$

输入到输出
$
[  
G_{vg}(s)=\frac{\hat V_o(s)}  {\hat V_{in}(s)}  
]
$
随后即可进行：

- 拉普拉斯变换
    
- 极点零点分析
    
- Bode 图分析
    
- 环路补偿设计
    

---

## 4. 状态空间（State Space）

### 什么是状态？

能够唯一描述系统未来行为的最小变量集合。

对于 Buck：

状态变量通常选择
$
[  
x=  \begin{bmatrix}  i_L\  v_o  \end{bmatrix}  
]
$

因为：

- 电感储能
    
- 电容储能
    

MOS、二极管、电阻均不储能，因此通常不是状态变量。

---

### 状态方程

写成统一形式：
$
[  
\dot x=Ax+Bu  
]
$

输出
$
[  
y=Cx+Du  
]
$
其中

- (A)：系统矩阵
    
- (B)：输入矩阵
    
- (C)：输出矩阵
    
- (D)：直通矩阵
    

---

## 5. 状态空间平均法（State-Space Averaging）

### 为什么需要？

Buck 每个 PWM 周期都在两个拓扑之间切换：

MOS 导通：
$
[  
\dot x=A_1x+B_1u  
]
$
MOS 关断：
$
[  
\dot x=A_2x+B_2u  
]
$
因此系统不是连续线性系统。

---

### 基本思想

PWM 频率远高于系统动态，因此只关心一个周期内的平均行为。

按占空比进行加权平均：

$
[  
A=DA_1+(1-D)A_2  
]
$
$
[  
B=DB_1+(1-D)B_2  
]
$
得到连续平均模型：

$
[  
\dot x=Ax+Bu  
]
$

---

### 为什么还要小信号？

虽然完成平均后消除了开关动作，但矩阵仍依赖于占空比：
$
[  
A=A(D)  
]
$
因此继续进行工作点线性化：
$
[  
D=D_0+\hat d  
]
$
最终得到小信号状态方程，再经拉普拉斯变换得到传递函数。

---

```text
Buck/Boost 电路
        │
        ▼

        │
        ▼

        ▼

        │

        │
        ▼

        │

        │

        │
        ▼

```

---

## 核心思想（一句话总结）

- **二阶系统**：来源于储能元件（L、C）形成的二阶微分方程。
    
- **状态空间**：用储能变量描述系统动态。
    
- **状态空间平均法**：把 PWM 的 ON/OFF 两种拓扑按占空比加权平均，得到连续模型。
    
- **小信号模型**：在工作点附近线性化平均模型，得到可用于控制设计的传递函数。
    
- **控制设计**：利用传递函数分析极点、零点、频率响应，并设计补偿器，实现稳定、高性能的闭环控制。
