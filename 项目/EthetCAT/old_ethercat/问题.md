# 环境配置
在clangformat.cmake文件内包含了一个叫作clangformat_executable的变量（set(CLANGFORMAT_EXECUTABLE clang-format)）,它需要一个clang-format的程序
但是环境中没有全局的clang-format，需要传入一个clang-format
在cmake的页面内写入`-DCLANGFORMAT_EXECUTABLE=xxx路径`
cmake传参数的方式`-D变量名=值`

## clang-format
`clang-format` 是 LLVM/Clang 提供的一个 **C/C++ 代码格式化工具**。它不负责编译、链接，也不负责查找库，只负责把源代码按照统一风格重新排版。
例如它可以把：
```
if(x){foo(1,2);}
```
格式化成大概这样的形式：
```
if (x) {
    foo(1, 2);
}
```
具体缩进几个空格、大括号位置、空格数量等，由项目根目录的 [.clang-format](/home/jasonbrown/RM/27/rm_ecat_fw/.clang-format) 配置决定。你的工程中的脚本最终会执行类似下面的命令：
```
clang-format -style=file -i 文件名.c
```
其中：
- `-style=file`：读取项目里的 `.clang-format` 配置。
- `-i`：直接修改原文件。
- `文件名.c`：要格式化的文件。****
==看起来就是一个格式化风格工具==
区别：
- `clang-format`：格式化 C/C++ 源代码。
- `clangd`：给编辑器提供跳转、补全和索引。
- `clang`：C/C++ 编译器
- `arm-none-eabi-gcc`：真正编译 STM32 固件的交叉编译器。
- `clang-format` 也不是外部函数库
