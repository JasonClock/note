# 大学四年目标
如果你的目标是：

> **毕业时应聘硬件工程师（电源、电机控制、机器人、汽车电子、新能源、嵌入式硬件）**
> 
> 并且面试官问一句，你能从硬件一路聊到软件、控制、Linux、系统架构，甚至项目管理。

那我会把你的大学四年压缩成一个**“总工程师培养路线”**。

你的项目不应该是：

- 做个Buck
    
- 做个飞控
    
- 做个LoRa
    

这种互相独立的项目。

而应该是：

```text
统一技术栈

项目1：数字电源平台
      ↓
项目2：能源变换系统
      ↓
项目3：全手搓飞控
      ↓
项目4：机器人控制平台

所有项目共用：

STM32
PCB设计
RTOS
Linux
数据库
通信
控制理论
```

这样面试官会发现：

你不是做了4个项目。

而是在做一个越来越大的工程系统。
