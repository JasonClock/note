# [CRC校验的原理与实现](https://blog.csdn.net/weixin_44256803/article/details/105805628)

**循环冗余校验**（Cyclic Redundancy Check，CRC）是一种常用于检测数据传输或存储过程中是否出现错误的校验方法。CRC的核心思想是将数据视为一个长数字，通过模二除法计算出一个固定长度的校验码。这个校验码随数据一起传输，接收方再次计算校验码，通过比较两个校验码来判断数据是否完整。

## CRC校验的基本原理

CRC校验的基本原理涉及到模二运算，即不考虑进位的二进制加法运算，与异或运算等效。在CRC算法中，数据和一个预定义的除数进行模二除法，得到的余数即为CRC校验码。发送方将校验码附加到数据后面，接收方收到数据后，使用相同的除数进行模二除法，如果余数为零，则认为数据无误。

## CRC算法的数学描述

数学上，CRC算法可以描述为：设原始数据为**D(x)**，预定义的除数为**P(x)**，模二除法运算的余数为**R(x)**，即**R(x) =  (D(x) << r ) mod P(x)**，其中**r**为除数**P(x)**的最高次数。CRC码为**F(x)**，实际发送的数据为**T(x)**。CRC算法的目标是求解**F(x)**，使得**T(x) mod P(x) = 0**。

## 常用的CRC版本

CRC算法有多个版本，不同的版本有不同的多项式（除数），初始值，结果异或值，输入数据反转和输出数据反转等参数。例如，CRC-16/IBM使用的多项式是**0x8005**，初始值是**0x0000**，结果异或值是**0x0000**，输入和输出数据都需要反转。

## CRC算法的编程实现

CRC算法可以通过直接计算、查表法等多种方式实现。直接计算是按照CRC的原理，逐位处理数据，效率较低。查表法则是预先计算好一个表，根据数据直接查表得到CRC码，效率较高。例如，CRC-32的实现代码如下：
``` c
#include <stdio.h>

#define POLY 0x04c11db7 //用于做取模的除数 00000100'11000001'00011101'10110111

#define INIT 0xffffffff

#define XOROUT 0xffffffff

  
//32位的校验
unsigned int crc32(unsigned char* addr, unsigned int num) {

unsigned int crc = INIT;

while (num-- > 0) {

    crc ^= *addr++;//

    for (int i = 0; i < 8; i++) {

    if (crc & 0x80000000)//0x80000000 对应 10000000 00000000 00000000 00000000，判断目的，如果校验发现最高位是0，那就往左移，知道有1可以对齐
    {

        crc = (crc << 1) ^ POLY;//左移后异或上规定数

    } 
    else 
    {
    crc <<= 1;
       }

    }

}

return crc ^ XOROUT;

}

  

int main() {

unsigned char input[] = { '1', '2', '3', '4', '5', '6', '7', '8', '9' };//数据量

printf("CRC-32: 0x%08x\n", crc32(input, sizeof(input)));

return 0;

}
```


## 总结

CRC校验是一种有效的数据完整性校验方法，广泛应用于数据通信和存储领域。通过合理选择多项式和其他参数，CRC可以高效地检测出数据传输过程中的错误。在实际应用中，可以根据需要选择直接计算或查表法等不同的实现方式。
