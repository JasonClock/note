# 仲裁

## 为什么需要仲裁
当同时接收多个 CAN 包的时候，就得有先后，用仲裁决定先接收哪一个包。

## 仲裁方法
- 从高位到低位进行比较，做 AND 运算：1 & 0 = 0
- 优先级：遇到同一位 ID 位，选择为 0 的
- 即选 ID 最小的

举例（高位 → 低位）：
- ID1：000
- ID2：100
- ID3：010

| ID 地址 | 高位 | 次高位 | 最低位 |
| --- | --- | --- | --- |
| ID1 | 0 | 0 | 0 |
| ID2 | 1 | 0 | 0 |
| ID3 | 0 | 1 | 0 |
| 选择 | 选择 ID1、3，排除 ID2 | 选择 ID3，留下 ID1 | 只剩下 ID1 |

## 电平定义
- 显性电平（原文标注逻辑 0）：压差为 0
- 隐性电平（原文标注逻辑 1）：压差为 2V
